# Rust VAD implementation plan

Goal: accelerate speech analysis without changing the model or export behavior.
Architecture: Node sends PCM to a Rust CLI using existing native ONNX shared library.
Spec: ../specs/2026-10-24-rust-vad-design.md

- [x] Add integration tests for Rust/Node probability parity, silence, spoken audio,
  partial/empty input and fallback; observe failure before implementation.
- [x] Add pinned ort-based Rust worker with binary stdin/stdout protocol and release
  build command. Keep model state local per invocation; single inference thread.
- [x] Integrate automatic worker selection, bounded process execution, output
  validation, and Node fallback into server/vad.mjs.
- [x] Build Rust in Docker; document local build and backend selection.
- [x] Add reproducible synthetic speech benchmark including process startup.
- [x] Run native parity tests, complete npm test, npm run build, and benchmark.

Review focus: endian correctness, final padding, recurrent state isolation,
malformed/crashed subprocess output, absent Rust binaries in local installations.

## Verification and decisions

- Native release build and npm run build:native pass (Rust 1.99.1, Linux x64).
- npm test: 41 passed, 0 failed, 0 skipped with native worker built.
- npm run build passed; git diff --check passed.
- Final isolated synthetic 300-second speech benchmark, three-run medians:
  Node 1681 ms, Rust 1198 ms (1.40x); process/model startup included.
- Ruling: automatic Rust selection starts at 300 seconds. Startup overhead made
  short-clip results worse and one-minute results variable. Explicit rust mode
  still supports all lengths. Node fallback remains available for every length.
- Independent static review identified optional native tests breaking npm test on
  Node-only installs; fixed by skipping native-only tests when the binary is absent.
- Docker multi-stage configuration updated; Docker executable unavailable locally,
  so an actual image build was not run. Native executable and shared runtime were
  verified directly on Linux x64.
